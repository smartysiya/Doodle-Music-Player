#  Doodle Music Player

A production-ready music player with real-time audio visualization, 
beat detection, and animated doodles.

Built with React, Web Audio API, Express, PostgreSQL, and TypeScript.

##  Features
- Real-time waveform visualization (Canvas)
- Beat detection with FFT analysis
- Full REST API with authentication
- PostgreSQL database with Prisma
- Automated CI/CD with GitHub Actions

##  Tech Stack
React | TypeScript | Web Audio API | Express | PostgreSQL | GitHub Actions
